# Cafe-website

A modern cafe website designed to showcase a cafe and provide visitors with an attractive and user-friendly browsing experience.

**Technologies Used**
- HTML
- CSS
- JavaScript

## How to Run the Project

You can view the live project here: https://mominamahmood6789-commits.github.io/Cafe-website/index.html

Alternatively, to run it locally:

1. Clone or download this repository.
2. Open the project folder.
3. Double-click the `index.html` file.
4. The website will open in your default browser.

**Recommended Browser:** Google Chrome or Mozilla Firefox.
